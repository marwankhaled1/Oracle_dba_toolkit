# Oracle Database 19c DBA Toolkit

A comprehensive collection of administrative notes, production scripts, configuration templates, and troubleshooting runbooks for Oracle Database 19c environments (Single Instance, RAC, and Data Guard).

---

## 📂 Repository Structure

```text
oracle-19c-dba-toolkit/
├── docs/                      # Conceptual notes & administration guides
│   ├── architecture/          # Grid Infrastructure, RAC, and ASM notes
│   ├── backup-recovery/       # RMAN backup strategies & duplication guides
│   └── patching/              # RU, OJVM, and Opatch procedures
├── scripts/                   # Executable automation
│   ├── bash/                  # Shell scripts (health checks, env setups)
│   ├── python/                # Python utility scripts
│   └── sql/                   # SQL & PL/SQL monitoring/admin scripts
├── configs/                   # Sanitized configuration templates
└── troubleshooting/           # ORA- error runbooks and post-mortems
```
